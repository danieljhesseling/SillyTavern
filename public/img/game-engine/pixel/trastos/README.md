# Iconos de trastos

Un icono por fila de `public/compendio/trastos.json`. 64×64, fondo transparente, hechos con PixelLab (pixflux).

- `forma-farol.png` — un farol de hierro con una vela encendida dentro.
- `forma-ganzuas.png` — un juego de ganzúas y herramientas finas de metal.
- `forma-cadena.png` — una cadena de hierro enrollada en círculo.
- `forma-odre.png` — un odre de cuero con tapón.
- `forma-morral.png` — un morral de cuero con hebilla y correa.
- `forma-amuleto.png` — un amuleto de bronce y hueso colgado de un cordón.
- `forma-cuerda.png` — un rollo de cuerda de cáñamo.
- `forma-pico.png` — un pico de minero.
- `forma-pala.png` — una pala de cavar.
- `forma-catalejo.png` — un catalejo de latón.
- `forma-tienda.png` — una tienda de campaña pequeña de lona.
- `forma-yesquero.png` — una caja de yesca abierta con pedernal y eslabón.
- `forma-antorcha.png` — una antorcha encendida.
- `forma-sal.png` — un saco de arpillera del que se sale sal blanca.
- `forma-campana.png` — una campana de bronce.
- `forma-espejo.png` — un espejo de mano con marco dorado.
- `forma-red.png` — una red de pesca cuadrada con pesos en las esquinas (el relleno oscuro del centro se quitó a mano para que se vea a través).
- `forma-cepo.png` — un cepo de acero con mandíbulas dentadas.
