# Retratos · La Maldición de Strahd

Bustos de 128×160 con fondo transparente, tono gótico de Barovia. El nombre del archivo es el `id` del PNJ en `public/mundos/strahd.pack.json`; los confidentes y el propio Strahd (que en el paquete está en `bestiary`, no en `npcs`) van con el slug de su nombre.

## Strahd

- `strahd-von-zarovich.png`: Strahd von Zarovich. Vampiro aristócrata pálido, pelo negro peinado hacia atrás, ojos rojos, capa negra de cuello alto forrada de rojo.
