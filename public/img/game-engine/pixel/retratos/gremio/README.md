# Retratos · Puerto Alba (gremio)

Bustos de 128×160 con fondo transparente, para la caja de diálogo. El nombre del archivo es el `id` del PNJ en `public/mundos/gremio.pack.json`.

- `brunilda.png`: Brunilda, Maestra del gremio. Aventurera retirada, pelo gris en trenza, jubón de cuero, brazos cruzados y mirada seca.
- `tomas.png`: Tomás, Posadero. Hombre grueso y sonriente, bigote poblado, delantal blanco y una jarra en la mano.
- `marisa.png`: Marisa, Tendera del mercado. Joven de pelo rizado con pañuelo rojo y camisa verde, brazos cruzados, sonrisa de charla.
- `ramiro.png`: Ramiro, Herrero. Barba negra, delantal de cuero, brazos cruzados (el retrato de referencia del estilo).
- `elvira.png`: Madre Elvira, Sacerdotisa de la capilla. Mujer serena con toca gris y colgante de sol dorado.
