# Iconos de clase

Un icono por fila de `public/compendio/clases.json`. 64×64, fondo transparente, hechos con PixelLab (pixflux).

- `guerrero.png` — dos espadas cruzadas sobre un escudo rojo oscuro (ya existía; se conserva).
- `barbaro.png` — dos hachas grandes cruzadas sobre una piel de lobo.
- `picaro.png` — una capucha oscura con la cara en sombra y una daga delante.
- `clerigo.png` — un símbolo sagrado de sol dorado montado sobre una maza.
- `druida.png` — una rama de roble con hojas y bellotas, como un bastón.
- `mago.png` — un libro de conjuros abierto y un bastón con un cristal azul.
- `bardo.png` — un laúd de madera.
- `explorador.png` — flechas cruzadas de plumas verdes sobre un carcaj.
- `soldado.png` — un escudo redondo de madera con una lanza detrás y un estandarte rojo.
- `erudito.png` — un pergamino enrollado, una pluma y un farol pequeño.
